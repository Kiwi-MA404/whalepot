## 核心创意：回声即视觉
主角倾汤头顶扣着一口锅，**看不见世界**。
按 `L` 敲锅，回声会替她把周围"画"出来：

- 照亮敌人、隐藏平台、可拾取物
- **但整个区域的东西都会听见你**，沉睡的敌人会被惊醒
- 所以"看见"是有代价的——想看得更清楚，就要承担被发现的风险

这是玩法，也是剧情隐喻。

## 操作
| 键 | 动作 |
|---|---|
| A / D | 移动 |
| 空格 | 跳跃（可二段） |
| J | 轻击（三连） |
| K | 重击（破防、可挡弹道） |
| L | **敲锅 · 回声** |
| Shift | 翻滚（有无敌帧） |
| E | 交互 / 对话 / **坐火** |
| Q | 喝汤回血 |
| R | 坐火（E 也可以） |
| Esc | 暂停 |

支持手柄。

## 魂系系统
- **魂**：击杀获得，死亡后**全部掉落在原地**，回去捡回；再死一次就永久失去
- **坐火**：恢复血量与汤，**同时存档**，但所有敌人复活
- **存档点 = 火堆**：坐火即存档。标题页出现「继续 · 上次的灶」，刷新页面不丢进度
- **体力条**：攻击、翻滚消耗，砍空会力竭
- **Boss 三阶段**：血量 50% / 22% 时转换，招式升级（冲锋、三重砸地、弹幕）
- **Boss 竞技场地面完全平坦**：Boss 体型大，任何台阶都会让它卡住；另加 2 秒卡住自动脱困
- **二周目**：通关后可进入，敌人血量 +55%/周目、伤害 +35%、魂 +50%，Boss 血量 +45%

## 世界
四个连续章节，一次读图走到底：

1. **灰烬滩** — 起点，枯树与墓碑
2. **漏雨廊** — 隐藏平台只有回声能照亮
3. **骨钟道** — 骨钟、汤卫、锈钥匙
4. **大汤殿** — 汤主 · 无口

## 隐藏彩蛋 🥚
在**大汤殿、站在汤主面前**，连续敲锅 **3 次**（每次间隔 < 2.5 秒）：

> 回声在它身上……空了一下。

汤主会直接消散，进入**独立隐藏结局「一记回声」**——它不属于正常通关流程，
结束后你可以选择「回去打完这一场」，照样打正式结局。

线索埋在剧情里：**汤主 · 无口**。它不是没有嘴，是**没有回声**。

## 剧情
七天前，海被熬成了一锅汤。
她头顶的锅盔，是母亲留给她的最后一样东西。
掀开锅盖，她就能看见真实——但真实里全是汤。

打败汤主后有结局分歧。

## 技术
- 纯 HTML/CSS/JS，无构建、无依赖
- 场景美术**程序化绘制**（Canvas 2D）
- 全部音效**实时合成**（WebAudio），无音频文件
- 主角使用**原版角色精灵**：`assets/hero.png`（自动抠除沙地背景 → 3 倍 LANCZOS 放大 → 轻度锐化）
- `assets/portrait.jpg` 为设定原图存档

## 快速开始

```bash
git clone https://github.com/Kiwi-MA404/whalepot.git
cd whalepot
open index.html          # macOS
# 或 Windows 下双击 index.html
```

**无需安装任何依赖**，也不需要构建或本地服务器。
